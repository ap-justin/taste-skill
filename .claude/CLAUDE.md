## Team

Load **`kru:lead`** before building, reviewing, or dispatching a seat — it carries how the team works.

- **skills** — `skills/*/SKILL.md` + their references, shipped as the plugin in `.claude-plugin/` and as zips in `dist/` (`scripts/build-zips.sh`); author on `kru:writing-for-agents`, package on `skill-packaging`
- **asset scripts** → `kru:node-developer` — `scripts/*.mjs` (README banners, buttons, sponsor badges)
- no manifest: no `verify`, `test` or dev server

A slice reaching a stack no seat above covers is a question for the user, naming the seat it would need — never a nearby seat pressed into the gap.
